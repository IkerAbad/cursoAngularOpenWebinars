# cursoAngularOpenWebinars

Proyecto de partida de Angular 14 (mayo de 2023) creado para seguir un curso de Angular de OpenWebinars. De momento solo contiene el esqueleto generado por Angular CLI: la página sigue mostrando la plantilla de ejemplo y no hay componentes propios.

`ng build` compila sin errores. No he abierto la aplicación en un navegador desde aquí.

## Cómo probarlo

```
npm ci
npx ng serve
```

y abre `http://localhost:4200/`.

# cursoAngularOpenWebinars (English)

A starter Angular 14 project (May 2023) created to follow an Angular course from OpenWebinars. For now it only holds the skeleton generated by Angular CLI: the page still shows the sample template and there are no components of my own.

`ng build` compiles without errors. I have not opened the app in a browser from here.

## Trying it

```
npm ci
npx ng serve
```

then open `http://localhost:4200/`.
